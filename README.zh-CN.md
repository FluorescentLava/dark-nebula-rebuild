# Dark Nebula Rebuild

[English](README.md)

基于 Unity 6 的 **Dark Nebula Episode One** 与 **Episode Two** 复原项目，整合 iOS 和 Android 版本内容，适配现代移动设备。

## 功能（0.4.0-Beta）

### 核心功能

- [x] 现代 Android 支持与竖屏高屏适配。
- [x] 两代关卡、玩法、美术和特效复原。
- [x] 二代石阵生成补景与原版桥面处于同一图层，在镜头升降和旋转时保持贴合。
- [x] 本地进度、关卡评级与排行榜。
- [x] 关卡结算与可跳过的计分动画。
- [x] 恢复二代原版 intro 与 extro 影片、音轨和两步跳过操作。首次点击显示游戏科幻字体的灰色提示，松开后再点击提示区域即可跳过。首次进入主菜单播放 intro，新游戏直接进入第一关，不重复播放片头。主菜单 Credits 播放 extro 后返回主菜单，通关时播放 extro 后进入 EndOfGame。
- [x] 两代 iOS Unity 导出、Xcode 编译与未签名 IPA 打包技术链路已验证。

### 拓展功能

- [x] 沿用原版设置界面，扩展计时器、语言、震动与选球控制，调整间距并整体居中。
- [x] 两代可选关卡计时器，默认开启。
- [x] 两代选球功能，通过免费收集碎片购买解锁。
- [x] 英语与简体中文，内置几何风格中文字体，调整字形大小、全角字宽与标签居中。
- [x] 恢复二代设置与排行榜中文选项切换时的字距动画，保留原有字形、静止布局和颜色。
- [x] 两代确认框背景铺满长屏视图。
- [x] 中文昵称输入与排行榜显示，采用匹配原版风格的黑体。
- [x] 高质量音频解码与位置立体声效。
- [x] 关闭、原版、增强三种震动模式，默认增强。
- [x] 增强震动包含跳板多段衰减、普通道具轻震、碎片与 1UP 中震，以及不被较弱事件打断的 650 毫秒死亡反馈。
- [x] 每次关卡开始前完成后台传感器校准。
- [x] Windows Unity 调试用 WASD 控制，Release 不包含。

## 0.4.0-Beta 更新

一代主菜单的“第二章”按钮在 Android 和 iOS 上优先打开已安装的第二章；本机未安装或无法启动时，跳转到本仓库的 [Releases 页面](https://github.com/FluorescentLava/dark-nebula-rebuild/releases)。iOS 第二章注册对应启动链接。两代 iOS 导出均将各自原版图标配置到所有受支持的应用图标槽，覆盖 iPhone、iPad 和 App Store 图标。

两代 iOS 隐藏状态栏。二代没有关卡进度时，“继续游戏”置灰并禁用，首次片头结束及从设置返回后均保持正确状态。“新游戏”直接进入第一关，不再重复播放片头；已有进度时仍需先确认清除存档。

两代增强计分震动跟随数字实际滚动状态持续触发短脉冲，滚动结束或跳过时立即停止计分反馈，保留更高优先级的星级奖励震动。iOS 的计分脉冲使用原生轻触反馈。

## 0.3.7 更新

一代排行榜保留头像，复用二代的用时、日期、英文表头字体和星星素材，收紧左侧留白，统一字号、颜色及文字位置。文字按字体的精确度量对齐可见字形，统一处理中英文、按钮和关卡标签的锚点，移除排行榜昵称的单独偏移补偿。结算页补充昵称输入，在确认昵称后将本次成绩保存到本地 Top 10。主菜单新增成就入口，沿用原徽章，显示全部 14 项金星成就及解锁进度，支持中英文。

一代设置和关卡准备的选球入口共用同一个界面与控制器，保留原版滑动预览、碎片贴图、购买和装备，暂停时也能切换和返回。一代原版碎片余额面板继续跟随界面布局；仅二代取消移植的余额底框，将碎片图标与数量放在选球页内容区的左上方，随整页适配，不再贴屏幕顶端。碎片拾取显示“获得 1 个碎片”；一代先恢复提示缩放，再计算文字对齐，两代均修复提示到期后的重复回收，保证首次与连续拾取都能正常显示。

二代排行榜同步一代原头像，长昵称按实际宽度自动缩小，为用时预留空间。英文、中文和混排昵称完整显示，切换列表后短昵称恢复正常字号。选球界面修复复制按钮的输入碰撞框，恢复返回、兑换和装备操作；英文剩余命数能正确替换数字。石阵 3D 转场恢复旧版上方树冠延展与林冠边缘处理，同时保留现有下方补景和原生镜头运动。Android 增强震动明确声明游戏用途，修复短促拾取反馈被系统误判为触摸反馈而关闭的问题。

两代关内设置复用主菜单设置逻辑，暂停、设置、校准与确认框使用黑色半透明背景；校准页保留大标题与正常字号正文。加载和定时角度教学期间阻止返回键及边缘返回手势打断转场，完成后恢复正常导航。同一菜单贴图的页面统一背景大小、位置、上下渐变和黑边范围。结算昵称随最后一段计分结果渐入，排行榜补充大字号标题，修复评级提示与昵称重叠。中文即时消息复用英文的渐变和左下阴影，修复底部裁切。一代机关同步修复高屏范围的休眠唤醒及变速跳变。

一代关卡提示恢复原版左图右文的布局：五种提示保留各自配套贴图，右侧文字块内部左对齐，并沿用原版位置与列宽。旧联网文案改为本地功能说明：成就提示引导到成就界面查看全部 14 项成就及解锁进度，其他提示说明自动保存、收集碎片解锁球体、本地排行榜和双指校准。中英文切换与重复展示使用相同布局；升级徽章的“解锁 / UNLOCK”文字补齐翻译并按实际字形居中。

## 0.3.6 更新

二代移动与旋转机关在检查点调整难度时保持当前位置，修复高屏下方仍可见的尖刺突然跳回运动路径另一端的问题。正弦障碍休眠后能完整恢复更新和物理状态。Android 打包前校验音乐导入资源，石阵补景改用跟随原生地形的两块小型遮罩贴图，扫描光带在高屏可视范围外完成运动。

iOS 提供未签名 IPA，需要 Apple 签发的签名证书与描述文件，才能安装到普通 iPhone 或 iPad。

iOS 发布文件统一命名为 `DarkNebula-Episode1-<版本>-iOS.ipa` 和 `DarkNebula-Episode2-<版本>-iOS.ipa`，不添加 `unsigned` 后缀。签名状态在发布说明中注明。

## 从源码构建

从选定的 GitHub Release 下载 **Source code (zip)** 或 **Source code (tar.gz)**，也可直接检出对应标签。GitHub 会按发布标签自动生成源码归档；额外上传的发布资产为两代 Android APK 和两代未签名 iOS IPA。使用 Unity **6000.4.11f1** 分别打开 `EpisodeOne` 或 `EpisodeTwo` 工程，并安装所需的 Android 或 iOS Build Support 模块。源码归档不包含本地缓存、构建产物、验证工具或签名密钥。

Android 构建入口为各工程 `Assets/Editor` 下的 `BuildEpisodeOne.Build` 和 `BuildEpisodeTwo.Build`，目标为 ARM64，最低 Android API 26、目标 API 35。需配置 Android SDK、NDK **27.2.12479018** 与 JDK **17**；构建入口可通过 `DARK_NEBULA_JDK17` 读取 JDK 路径。自行分发 Android 包时需使用自己的签名密钥库。

iOS 构建需将对应工程切换到 iOS 并导出 Xcode 工程。仓库的手动 **Build iOS** GitHub Actions 工作流包含 Unity 导出、Xcode Release 编译和未签名 IPA 打包步骤。构建需要 macOS 与 Xcode；真机安装还需要 Apple 签名和描述文件。
